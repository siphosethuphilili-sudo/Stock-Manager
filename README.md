 Small Business Stock Manager

 Project Overview

Small Business Stock Manager is an Android application designed to help small business owners manage and monitor their inventory efficiently. The application provides a simple way to add, update, delete and view products, track stock quantities and identify products running low on stock.

Purpose of the Project

The purpose of this application is to simplify inventory management for small businesses by reducing manual record-keeping, minimising stock management errors and helping business owners maintain accurate inventory records.

 Key Features

- **Product Management:** Add, edit, delete and view products.
- **Stock Tracking:** Monitor available product quantities.
- **Low-Stock Monitoring:** Identify products that need restocking.
- **Product Search:** Quickly find products in the inventory.
- **Inventory Management:** Keep product information organised.
- **Local Data Storage:** Store inventory records locally.

Technologies Used

- Java
- Android Studio
- XML
- Room Database (SQLite)
- Android SDK
